# Apple-TV-2-jailbreak-guide

Since all the tools avalaible are outdated, here's the fix:

The only Mac OS version that seemed to work for me is Big Sur. May work with other OS tho.
DO NOT USE A VIRTUALIZED OS.

   * Install Itunes via Retroactive and complete the initial setup

   * Install Blackb0x from the official github page.

   * Plug in in the ethernet cable, micro usb cable and power cable (in this order) and restore Apple TV 2 to 5.3 (6.1.4) with finder

   * Open Itunes and minimize it

   * Open Blackb0x and press Jailbreak

Note: After Blackb0x says "Waiting for reboot" expect a crash, it's important to NOT touch anything for approximately 5 minutes.

*NEVER unplug the ethernet cable until you are sure that Kodi it's on your main page, if you don't see it immediately try to wait another 5 minutes.*

If it doesn't work, repeat the process.
Hopefully this will be useful for someone now or in the future, happy jailbreaking :P
